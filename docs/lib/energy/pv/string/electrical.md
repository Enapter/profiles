# PV String Electrical Measurements

Voltage, current, and power measurements for a single PV MPPT string.

## Telemetry

### `pv_string_voltage`

- **Display name:** PV String Voltage
- **Type:** `float`
- **Unit:** V

DC voltage of the solar panel string.

### `pv_string_current`

- **Display name:** PV String Current
- **Type:** `float`
- **Unit:** A

DC current of the solar panel string.

### `pv_string_power`

- **Display name:** PV String Power
- **Type:** `float`
- **Unit:** W

DC power of the solar panel string.
