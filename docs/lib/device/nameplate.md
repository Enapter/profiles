# Device Nameplate

Includes typical nameplate information like vendor, model, and serial number.

## Properties

### `vendor`

- **Display name:** Vendor
- **Type:** `string`

Manufacturer of the device.

### `model`

- **Display name:** Model
- **Type:** `string`

Model name/number.

### `serial_number`

- **Display name:** Serial Number
- **Type:** `string`

Unique serial number of the device.
