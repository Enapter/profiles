# Grid Charging/Feed-in Configuration Status

Information about grid charging/feeding-in configuration status.

## Properties

### `grid_charge_enabled`

- **Display name:** Grid Charging Enabled
- **Type:** `boolean`

Whether charging from grid is enabled.

### `grid_feed_in_enabled`

- **Display name:** Grid Feed-in Enabled
- **Type:** `boolean`

Whether feeding energy to grid is enabled.
