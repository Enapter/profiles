# Grid Connection Mode

Configured grid connection mode for the inverter.

## Properties

### `grid_mode`

- **Display name:** Grid Mode
- **Type:** `string`

**Values:**

| Value | Name | Description |
|-------|------|-------------|
| `grid_tied` | Grid-tied | Inverter is configured to operate in grid-tied mode. |
| `off_grid` | Off-grid | Inverter is configured to operate off-grid (grid-forming mode). |
