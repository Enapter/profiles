# Single-Phase Inverter

Provides AC measurements for a single-phase inverter.

## Telemetry

### `ac_frequency`

- **Display name:** AC Frequency
- **Type:** `float`
- **Unit:** Hz

AC output frequency.

### `ac_l1_power`

- **Display name:** L1 Power
- **Type:** `float`
- **Unit:** W

AC power on phase L1.

### `ac_l1_voltage`

- **Display name:** L1 Voltage
- **Type:** `float`
- **Unit:** V

Voltage on phase L1 to neutral.

### `ac_l1_current`

- **Display name:** L1 Current
- **Type:** `float`
- **Unit:** A

Current on phase L1.
